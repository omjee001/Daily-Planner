Daily Planner 📅

Daily Planner is a lightweight, responsive web app designed to help you organize your day, manage tasks, and stay productive.

✨ Features

* ✅ Task Management — Add and organize daily tasks.
* 📊 Weekly Summary — Get a quick overview of your week.
* 🗓️ Monthly Calendar — View and navigate dates.
* 🔥 Productivity Streaks — Track your consistency.
* 🎨 Multiple Themes — Customize the appearance with different themes.
* 📱 Responsive Design — Use it on desktop and mobile screens.
* 📦 Installable PWA — Install it like a desktop app in supported browsers.
* 📴 Offline Support — Access the app offline after it has been loaded and cached.

Built with: HTML, CSS, and JavaScript.

Note: Tasks are stored locally in the browser, so they may not automatically sync between different devices or browsers.
